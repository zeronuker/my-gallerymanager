# ClaudeBorne Gallery Manager

One Android app that replaces both the gallery and the file manager. Same look as the other ClaudeBorne apps.

## Tabs
- **PHOTOS** – date-grouped grid, pinch to resize, filter (photos / videos / favorites), sort, search, multi-select (share, favorite, trash, vault).
- **ALBUMS** – every folder with media.
- **FILES** – browse all storage and SD cards, search, sort, copy / move / rename / zip / unzip / share, file trash (30 days), built-in PDF, text and music viewers.
- **TOOLS** – storage breakdown, large files, recent files, duplicate finder, junk cleanup, private vault (AES-256, locked by the screen lock).
- **TRASH** – photo trash and file trash.

Viewer: zoom, video, info (EXIF), favorite, slideshow, edit (rotate, mirror, crop → saved as a copy).

## Permissions
Photos/videos access for the gallery; "All files access" for the Files and Tools tabs (granted in Settings, asked when you open those tabs). The app is installed as an APK, not from the Play Store.

## Build
Push to a `feature/**` branch or run the *Build APK* workflow; the debug APK is attached to the run.
